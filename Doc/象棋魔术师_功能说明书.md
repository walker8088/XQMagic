## 一、产品概述

**象棋魔术师（XQMagic）** 是一款运行于 Windows 平台的免费中国象棋桌面软件，采用 Python + PyQt5 开发。核心定位是 **打谱研究、残局练习、人机对抗与局面分析**。

| 项目 | 信息 |
|------|------|
| 当前版本 | `1.26.1` |
| 运行环境 | Windows 8+（Python ≥ 3.11） |
| 开源引擎 | Pikafish（皮卡鱼）为主要测试引擎 |
| 协议支持 | UCI / UCCI 引擎协议 |

---

## 二、五大核心模式

| 模式 | 名称 | 功能描述 |
|------|------|----------|
| `Free` | **自由练习** | 从任意局面自由走子，云库/引擎实时评估着法质量，棋谱可保存到个人数据库 |
| `EngineAssit` | **引擎辅助** | 引擎在后台实时分析当前局面，在棋盘上显示箭头提示最佳着法 |
| `EngineFight` | **人机对战** | 引擎扮演红方或黑方，与人类玩家对抗；局后可逐着复盘评分，标出劣着与推荐着法 |
| `Puzzle` | **杀法挑战** | 内置多套杀局集（梦入神机、适情雅趣 360 局等），红先胜排局，由简到难挑战，完成后自动进入下一局 |
| `EngineOnline` | **连线分析** | 连接云端棋库（chessdb.cn），实时获取局面最佳着法与评分 |

## 十三、数据流

### 13.1 走子执行流

```
用户点击棋盘
  └─> ChessBoardWidget.mousePressEvent()
        └─> try_move() 验证合法性
              └─> tryMoveSignal.emit(from, to)
                    └─> MainWindow.onTryBoardMove()
                          └─> onMoveGo(iccs)
                                ├─ board.move_iccs() 执行走子
                                ├─ 创建位置字典，追加到 positionList
                                ├─ 更新 fenCache[new_fen]
                                ├─ historyView.onNewPostion()  添加着法行
                                ├─ updateStatus()  音效、状态栏
                                └─ changePositionSignal.emit()
                                      └─ onChangePosition()
                                            ├─ boardView.showMove()
                                            ├─ localSearch()  查询开局库
                                            ├─ cloudQuery.startQuery()  云库模式
                                            └─ runEngine()  引擎分析
```

### 13.2 引擎输出流

```
EngineManager._runOnce()
  ├─ 'bestmove' -> moveBestSignal -> MainWindow.onTryEngineMove()
  │     ├─ updateFenCache(fenInfo, isEngine=True)
  │     ├─ 如果是残局 -> onMoveGo(iccs) 自动走子
  │     └─ 否则 -> showBestHint()  棋盘箭头提示
  └─ 'info_move' -> moveInfoSignal -> engineView.onEngineMoveInfo()
        └─ 更新 MultiPV 分析树显示
```

### 13.3 云库查询流

```
CloudDB.startQuery(position)
  ├─ 检查 move_cache（已缓存则跳过）
  └─ 创建 NetQuery -> HTTP GET chessdb.cn
        └─ onQueryFinished()
              ├─ 解析管道分隔响应
              ├─ 分数转换为红方视角
              ├─ 计算与最佳着法的偏离度
              ├─ updateCache() -> Globl.fenCache
              └─ query_result_signal.emit()
                    └─ MainWindow.onCloudQueryResult()
                          ├─ updateFenCache(query)
                          ├─ 与引擎分析合并
                          └─ actionsView.updateActions()
```

## 十六、常见问题

### 引擎无法启动
- 检查 `XQMagic.ini` 中的引擎路径是否正确
- 确认引擎文件有执行权限
- 检查引擎依赖是否完整

### 数据库错误
- 确认 `Game/` 目录下的数据库文件存在
- 检查文件读写权限
- 尝试使用 `--clean` 清除设置后重启

### 云库查询超时
- 检查网络连接
- 云库服务器可能暂时不可用，切换为引擎优先模式
